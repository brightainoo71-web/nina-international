# Nina International: AWS Disaster Recovery & S3 Backup Integration Guide

## 1. Overview & Cloud Boundaries

This guide outlines how the client can configure and connect their own client-owned Amazon Web Services (AWS) account for automated, encrypted disaster recovery backups.

> [!IMPORTANT]
> To protect the user's personal identity and avoid unauthorized financial commitments, the application uses placeholders by default. No AWS resources or subscriptions have been created under the developer's personal identity. The client must provision their own AWS resources following this guide.

---

## 2. Estimated AWS Costs

For an educational institution of Nina International's scale (~1,000 students):
- **S3 Standard Storage**: ~5 GB/month = **\$0.12 / month**.
- **AWS KMS Customer Managed Key**: 1 Key = **\$1.00 / month**.
- **API PUT/GET requests**: < 10,000 requests/month = **\$0.05 / month**.
- **Estimated Total Cost**: **~ \$1.20 - \$2.50 / month**.

## 3. Client Provisioning Steps

### Step 1: Create an Amazon S3 Bucket
1. Log in to the [AWS Management Console](https://console.aws.amazon.com/s3/).
2. Click **Create bucket**.
3. **Bucket name**: `nina-international-school-backups-[client-account-id]`.
4. **AWS Region**: Select the closest region (e.g., `af-south-1` Cape Town or `eu-west-1` Ireland).
5. **Block Public Access**: Ensure **Block all public access** is **CHECKED** (Never make backups public).
6. **Bucket Versioning**: Enable **Bucket Versioning** to protect against accidental deletion or ransomware overwrites.
7. **Default Encryption**: Choose **Server-side encryption with AWS Key Management Service keys (SSE-KMS)** or Amazon S3 managed keys (SSE-S3).

---

### Step 2: Configure Least-Privilege IAM User & Policy
1. Navigate to the **IAM Console** > **Users** > **Create User**.
2. Name: `nina-backup-service-worker`.
3. Select **Attach policies directly** > **Create Policy** (JSON):
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowBackupUploadsAndVerification",
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:ListBucket",
        "s3:GetObjectVersion"
      ],
      "Resource": [
        "arn:aws:s3:::nina-international-school-backups-*",
        "arn:aws:s3:::nina-international-school-backups-*/*"
      ]
    },
    {
      "Sid": "AllowKMSEncryption",
      "Effect": "Allow",
      "Action": [
        "kms:Encrypt",
        "kms:Decrypt",
        "kms:GenerateDataKey"
      ],
      "Resource": "arn:aws:kms:*:*:key/*"
    }
  ]
}
```
4. Create access keys for the user and record the **Access Key ID** and **Secret Access Key**.

---

### Step 3: Configure AWS Secrets Manager for Server Pepper
1. Navigate to **AWS Secrets Manager** > **Store a new secret**.
2. Type: **Other type of secret**.
3. Key/value: `PEPPER_SECRET` = `[Generate 64-character random hex string]`.
4. Name: `nina/production/pepper-key`.

---

### Step 4: Connect Credentials in `.env`
Update `backend/.env` with the client's provisioned values:
```bash
AWS_REGION=eu-west-1
AWS_S3_BACKUP_BUCKET=nina-international-school-backups-123456789012
AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
AWS_KMS_KEY_ID=arn:aws:kms:eu-west-1:123456789012:key/your-key-uuid
```

## 4. Disaster Recovery & Integrity Verification

### Archive Format & Encryption
Every backup generated by Nina International:
1. Is serialized into standard JSON preserving document hierarchies.
2. Has its SHA-256 payload checksum calculated.
3. Is encrypted at rest using **AES-256-GCM** authenticated encryption (`iv:tag:ciphertext`).
4. Is stored with a default 30-day retention schedule.

### Verifying Archive Integrity
Administrators can verify backup integrity from the **Disaster Recovery** dashboard tab:
1. Click **Test Integrity** on any backup archive.
2. The server reads the archive, decrypts the payload in memory, verifies the SHA-256 checksum, and tallies collection records without touching the live database.
3. The result is logged to the Security Centre audit trail.
